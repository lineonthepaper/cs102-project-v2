# Face Recognition Models

## Current Setup

This project uses **FaceNet** model for face recognition, which provides significantly better accuracy than the previous ArcFace model.

FaceNet is used via the PyTorch engine, with the DJL (Deep Java Library) library.

## Model Files Required

### 1. Face Recognition Model (FaceNet)
- **File**: `face_feature.zip`
- **Size**: 99 MB
- **Status**: Already included in repository

### 2. Face Detection Model (Haar Cascade)
- **File**: `haarcascade_frontalface_alt.xml`
- **Size**: 661 KB
